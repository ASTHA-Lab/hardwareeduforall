Catalog

Nine modules, each tied to a design concept.

Surveyed means students answered a survey. Taught means the module ran, and there was no survey. Written means the lab is ready and has not been graded yet.

M1

Binary reverse engineering

Recover a room-temperature controller from an AT89C51 binary that ships with no source.

FieldEmbedded systemsDelivered, surveyed
 M2

Buffer overflow

Overrun a fixed buffer on an 8051, watch a secret return through R7, then repair the copy.

FieldEmbedded systemsDelivered, surveyed
 M3

Timing side channel

Measure an early-exit password check on the logic analyzer, then make the comparison constant-time.

FieldEmbedded systemsDelivered, surveyed
 M4

Board reverse engineering

Take a populated board with no schematic and produce a bill of materials and a block diagram.

FieldEmbedded systemsWritten material
 M5

Power side channel

Infer an unknown gate from supply-current spikes, and see what the measurement cannot tell you.

FieldDigital logicDelivered, no survey
 M6

Combinational logic locking

Build a 4-bit ripple-carry adder, then lock the carry chain with a key.

Supply chainDigital logicWritten material
 M7

Hardware Trojan insertion

Leave the locked adder alone, and add a trigger and a payload that corrupt it on one input.

Supply chainDigital logicWritten material
 M8

Sequential logic locking

Lock a UART transmitter in its state machine, so the key arrives over several clocks.

Supply chainDigital logicWritten material
 M9

Cache side channel

Read another process from the hit and miss timing of a shared last-level cache.

#ModuleCourseStatusDesign topicPlatformStudent work
M1 Binary reverse engineering Embedded systems Delivered, surveyed Compilation flow, instruction set, addressing modes, code and data spaces, stack pointer AT89C51 and Keil µVision Ten answers from the disassembly and the memory windows
M2 Buffer overflow Embedded systems Delivered, surveyed Stack frame, calling convention, saved return address, constant initialization AT89C51, Keil debugger Input length, secrets leaked, and a justified repair
M3 Timing side channel Embedded systems Delivered, surveyed Timer peripheral, cycle counting, serial-port setup, data-dependent branching AT89C51 and the debugger logic analyzer Timing tables for the vulnerable check and the repaired check
M4 Board reverse engineering Embedded systems Written material Microcontroller interfacing, serial protocols, power distribution, datasheets Undocumented board and a digital multimeter Bill of materials and block diagram; a schematic and a protocol if time allows
M5 Power side channel Digital logic Delivered, no survey CMOS switching, output transitions, charge transfer, truth tables Browser circuit simulator and a sense resistor Voltage plot, transition table, and the candidate truth tables
M6 Combinational logic locking Digital logic Written material Ripple-carry addition, carry propagation, hierarchical design, instantiation VHDL and an FPGA design suite Locked design, testbench, and waveforms for a correct key and a wrong key
M7 Hardware Trojan insertion Digital logic Written material Rare-condition decoding, conditional assignment, behavioral simulation VHDL and the locked adder from the locking lab Trigger and payload code, plus waveforms while dormant and while active
M8 Sequential logic locking Digital logic Written material Finite-state machines, reset and transition behavior, the UART frame VHDL UART transmitter Augmented state machine and waveforms for the right sequence and each wrong key
M9 Cache side channel Computer architecture Delivered, no survey Hierarchy, associativity, line size, set indexing, cycle-accurate timing A commodity x86 machine and its cycle counter A recorded probe-time series. No graded assignment was stated.
