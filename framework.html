Method

The contextual learning framework

Security content stays in a core course only when it makes the student use something that course already teaches. A topic that needs new machinery is a new course in disguise.

Core courses connect to security concepts, those concepts become course-specific modules, and only some of those modules have been assessed. Of the nine modules here, M1 through M4 belong to embedded systems, M5 through M8 to digital logic, and M9 to computer architecture.

Why integrate, instead of adding an elective

A1

Security education for all

Core design courses are required. The material reaches students who would never enroll in a hardware security elective, and it trains the faculty who already teach those courses.

A2

One picture, not two

Attacks that begin in implementation make more sense next to the circuit or the calling convention that produced them.

A3

A cost a department can keep

There is no new course to staff, equip, and defend at curriculum committee. The same pattern can later carry other topics a program needs, such as machine learning at the edge.

Five rules a module has to meet

C1

Concept coupling

The security topic is chosen because it exercises a design concept already on the syllabus. Its fame in the research literature does not decide the question.

C2

Instrument reuse

The module uses tools the laboratory already owns and the course already teaches: the debugger, the vendor environment, a logic analyzer, a multimeter. New equipment is the cost that stops a module from traveling.

C3

A paired countermeasure, where the target allows one

M2 asks the student to repair the overflow on a machine that has no stack canary and no address-space randomization. M3 re-measures a constant-time comparison on the same analyzer. M6 and M8 have the student build the protection. M1, M4, and M5 close without a defense, and the materials say so.

C4

Sequence alignment

The module is placed in the week the course covers the concept it exercises. A security lab that arrives after that unit’s exam has lost the coupling.

C5

Split acquisition and analysis

Some labs need more time than the slot allows. The bench work stays in the lab. Identification, trace reading, and waveform interpretation can finish outside it. Students in every surveyed cohort asked for worked examples and time, not for more equipment.

The suite does not yet reach fabrication-stage threats, physical unclonable functions, bus snooping, fault injection, or gate-level and device-level reverse engineering. The last of those needs decapsulation and imaging, which the instrument-reuse rule rules out. Breadth is not the goal. A course has room for a few modules, so a catalog is a menu.

A topic that fails the test

Fault injection on a cryptographic core needs a clock glitcher, a target with a crypto accelerator, and a treatment of the cipher. None of that is in a first embedded systems course, so the topic does not transfer. The same test rejected any module that would require a new instrument.
