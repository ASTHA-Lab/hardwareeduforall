Cache side channel

The topic

A cache side channel uses the cycle gap between a hit and a miss. On a shared last-level cache, that gap lets one process observe which lines another process touched.

Where it belongs

Course: Computer architecture. No course number is attached here.
Teach this after: the cache lecture, including hierarchy, associativity, line size, and set indexing. Part 1 can be given in that same week. Part 2 waits until students can explain a hit and a miss. At KU this lecture was given in Fall 2024.

Files and how to use them

Use the two slide decks as the class lectures. There is no homework file. Part 2 includes a measurement you can show in class. Students do not turn that measurement in.

  • Lecture, part 1. Use with the cache unit, or immediately after it. Hierarchy, the parameters that define a cache, and the geometry of the student’s own machine.
  • Lecture, part 2. Use only after part 1. Flush and reload, prime and probe, and the recorded hit and miss times.

The lecture

The course has already taught the cache as a performance structure: hierarchy, associativity, line size, and set indexing. This module uses the same structure as a side channel. A hit and a miss on a shared last-level line take different numbers of cycles, and that gap is wide enough to observe another process.

Outcome

The lecture closes on a recorded probe-time series. Across 90 probes, hits fall between 96 and 104 cycles and misses fall between 144 and 168. A threshold at 110 sits in a gap of about 40 cycles. No graded assignment is stated in the materials, and no survey was given.

Part 1. The cache as the course already draws it

Hierarchy from registers to main memory, the parameters that define a cache, and the three associativity arrangements. Students read the sizes, associativity, and line size of their own machine from the operating system and from a topology tool.

Part 2. The same structure as a channel

A flush-and-reload attack needs four things: memory shared with the victim, a high-resolution cycle counter, an instruction that evicts a chosen line, and a last-level cache shared across cores. The lecture walks the sequence. Flush a shared line, let the victim run, reload the line and time the access. The flush is the cache-line flush intrinsic with fences on both sides. The reload is timed between two reads of the timestamp counter. When no memory is shared, the lecture turns to prime-and-probe, which fills a set and times the later access to see whether the victim evicted a line.

Fall 2024 is the offering in which this lecture entered the computer architecture course. The two decks are listed above.
