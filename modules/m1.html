Binary reverse engineering

Recover a room-temperature controller from an AT89C51 binary that ships with no source.

The topic

Binary reverse engineering recovers what a compiled program does when the source is gone. On a small microcontroller, that work is how a student shows they can read the instruction set, the memory map, and a disassembly.

Where it belongs

Embedded systems. Assign this after the class has covered the compilation flow, the instruction set, addressing modes, and the split between code memory and data memory. The last homework question also uses the stack pointer. At the University of Kansas this module ran in EECS 388.

Materials and how to use them

This bundle has no overview video. The two decks are the class lectures. Plan about 30 to 40 minutes across the two sittings, then assign the homework. Lecture recordings from Spring 2023 stay in the instructor packet.

  • Lecture, part 1. Use in class before anyone opens the binary. Motivation, the 8051 instruction set and registers, and a Keil walkthrough.
  • Lecture, part 2. Use in class after part 1 and still before the homework. The memory map, addressing modes, and the disassembly and memory windows.
  • Homework handout. The graded assignment. Spring 2024 scored it at two points. Hand it out after both lectures.
  • unknown-1. The binary named in the handout. Students load it in Keil. Keep the source out of the student bundle.

Further reading

These sit outside the assignment. Use them to prepare the lecture, or hand them to a student who wants the work behind the exercise. They are not a walkthrough of the handout.

  • Azriel, Speith, Albartus, Ginosar, Shamir, and Paar, “A Survey of Algorithmic Methods in IC Reverse Engineering,” Journal of Cryptographic Engineering, vol. 11, pp. 299–315, 2021. Chip imaging and netlist recovery. This module stops at a firmware binary.

Videos

  • Reverse Engineering (Computerphile). What a binary still reveals after compilation. The examples use desktop tools, not the AT89C51.
  • Mohammad Tehranipoor on Integrated Circuit Security (UConn). A short faculty talk on why the chip is part of the security problem. Broader than this homework.

The exercise

The program behind the binary keeps a hospital room at a stable temperature. It reads a sensor value from external memory six times an hour, folds each sample into a running average with the previous average, compares that average with a threshold, and drives a port pin from the result. Students receive the binary and the part number, the Microchip AT89C51. They do not receive the source.

Outcome

The student recovers the sampling rate, the stored temperatures and their addresses, the threshold, and the output port, and explains what happens if the conditional jump that returns to the start of the program is replaced by a call.

What the lecture sets up

Two decks. The first is why reverse engineering shows up in embedded work, a short tour of the 8051 instruction set and registers, and a Keil walkthrough. The second is the memory map: internal memory, special-function registers, addressing modes, and the disassembly and memory windows the homework depends on.

The ten questions

The Spring 2024 handout, worth two points, asks the student to work only from the disassembly window.

  1. Address of the START label.
  2. Initial return address of the first call.
  3. How many times the program reads external memory.
  4. Last hour’s temperature, in decimal, before averaging.
  5. The mean temperature after averaging.
  6. The threshold, in decimal.
  7. The temperature values stored in external memory, and their locations.
  8. Which port carries the output signal.
  9. Whether that signal is actually driven from the temperatures found in memory.
  10. At C:0x034D the program returns to START with JNZ. What happens if that opcode is replaced by ACALL.

The last question is the stack. A call pushes a return address and this loop never executes a return, so return addresses accumulate until they disturb the rest of internal memory. The module stops there. It does not teach a countermeasure.
